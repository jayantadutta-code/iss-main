## 📌 Overview

**EOS Digital Space** is a creative and technology-driven SaaS organization focused on delivering modern, high-quality digital solutions for businesses and individuals. We specialize in cross-platform application development (Web, Android, macOS, Windows), UI/UX design, and customized cloud software engineered to enhance user experience and scale business growth.

This repository powers the official multi-landing digital portal for EOS Digital Space, showcasing our flagship product suite, interactive designs, and cross-platform application downloads.

---

## ✨ Key Features & Architecture

- 🎯 **Dynamic Multi-Theme Routing Engine (`index.html`)**: Automatically detects visitor device specifications (Mobile vs. Desktop) and dynamically routes them to one of 11 custom-crafted landing page experience designs (`index1.html` through `index11.html`).
- 💻 **Cross-Platform Software Delivery**: Direct downloads for Windows (`.exe`), Android (`.apk`), macOS (`.dmg`), and Web deployment.
- 🎨 **Modern & Fluid UI/UX**: Built with responsive layouts, glassmorphism aesthetics, smooth animations, dark/light modes, and seamless cross-browser support.
- 🛠 **Safari & Mobile Optimizations**: Integrated custom scripts (`fix_safari.js`) for cross-browser fallback handling and touch device responsiveness.

## 🚀 Getting Started

To run or inspect the landing pages locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/jayantadutta-code/iss-main.git
   cd iss-main
   ```

2. **Launch a local static server** (or open directly in your browser):
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   ```

3. **View in Browser**:
   Open `http://localhost:8000/` to test the dynamic router, or navigate directly to `http://localhost:8000/index1.html` through `index11.html` to explore individual design variants.
